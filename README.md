# 洛谷题目代码仓库

本仓库用于记录洛谷 OJ 题目的解题代码。

## 使用 Git 记录修改

### 基本命令

```bash
# 查看当前修改状态
git status

# 查看具体修改内容
git diff

# 添加修改的文件
git add <文件名>          # 添加单个文件
git add .                 # 添加所有修改

# 提交修改
git commit -m "提交说明"

# 查看提交历史
git log                   # 详细历史
git log --oneline         # 简洁历史

# 查看某次提交的详细内容
git show <提交ID>

# 回退到之前的版本（慎用）
git checkout <提交ID> <文件名>
```

### 推荐工作流程

1. 修改代码后，先查看状态：
   ```bash
   git status
   git diff
   ```

2. 添加并提交修改：
   ```bash
   git add P1433.cpp
   git commit -m "修复 P1433 距离矩阵 bug"
   ```

3. 定期查看历史：
   ```bash
   git log --oneline --graph
   ```
